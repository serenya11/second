About TechMart Microservice

This e-commerce application serves as the production workload inside our automated DevOps pipeline.

Pipeline Architecture Stack:
  • Application: Python Flask + Bootstrap 5
  • CI/CD Engine: Jenkins Pipelines
  • Containerization: Docker Desktop
  • Metrics Exporter: Prometheus Client SDK (`/metrics`)
  • Visualization: Grafana Dashboards
